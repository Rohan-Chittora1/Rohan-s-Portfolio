# Rohan.dev — Personal Portfolio

A modern developer portfolio built with React, TypeScript, TanStack Start, TailwindCSS, and Framer Motion.

Designed to showcase:

* AI engineering projects
* Full-stack development skills
* DSA/problem solving journey
* Modern UI/UX practices

---

## Frontend

* React 19

* Framer Motion

# Setup Instructions

## Clone Repository

```bash
git clone https://github.com/Rohan-Chittora1/Rohan-s-Portfolio.git
```

## Navigate To Project

```bash
cd Rohan-s-Portfolio
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

---

# Build For Production

```bash
npm run build
```
